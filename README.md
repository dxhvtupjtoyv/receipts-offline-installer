# Receipts — Free Offline Installer

![Category](https://img.shields.io/badge/Expense_Tracker-blue?style=flat-square)

## About

Receipts is a macOS and iOS application for organizing, tracking, and exporting expense receipts. Photograph receipts, extract data automatically with OCR, categorize expenses, and export reports for reimbursement or tax purposes. With iCloud sync across Apple devices and clean document export, Receipts simplifies the tedious task of business expense management for freelancers and self-employed professionals.

## Common Problems & Limitations

- **Apple Only** — macOS and iOS only
- **Commercial License** — Paid application
- **OCR Accuracy** — Automatic data extraction from receipts requires verification
- **Integration Limits** — Limited integration with accounting software
